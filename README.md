# Plan de Respuesta a Incidentes de Ransomware Basado en NIST

Este repositorio contiene un informe sobre un plan de respuesta a incidentes de ransomware basado en el framework NIST, utilizando como caso de estudio a la empresa ficticia TechCo. El documento analiza cómo un ataque de phishing permitió la propagación de ransomware dentro de la infraestructura de la empresa, afectando servidores críticos, bases de datos y sistemas de respaldo.

El informe desarrolla las fases de identificación, protección, detección, respuesta, recuperación y mejora continua, proponiendo medidas de seguridad como segmentación de red, backups offline, monitoreo SIEM, herramientas EDR y capacitación contra phishing. Además, se incluyen recomendaciones para fortalecer la resiliencia y continuidad operacional frente a futuros incidentes de ciberseguridad.
